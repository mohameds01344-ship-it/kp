KAREN ASHRAF ATTALAH — PORTFOLIO
Apple-inspired cinematic redesign

HOW TO RUN
1. Extract the ZIP folder.
2. Open karen_portfolio_site in VS Code.
3. Open index.html with Live Server, or double-click index.html.

FILES
- index.html: page content and sections
- style.css: responsive design system and visual styling
- script.js: navigation, scroll reveals, counters and project galleries
- assets/: portfolio photos, campaign work and brand logos

The site is static and can be hosted on GitHub Pages or any static hosting service.
